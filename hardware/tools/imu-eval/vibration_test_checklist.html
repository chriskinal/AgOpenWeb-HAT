3. MEMS Studio settings

Each intensity is run twice: A gives the raw data for our own fusion, B gives the chip's fusion (SFLP).

A: raw (fusion off)B: fusion on
Low-g accelhigh-performance, 240 Hz, ±16 gsame
Gyrohigh-performance, 240 Hz, ±500 dpssame
High-g accelon, 480 Hz, ±32 goff (fusion turns it off)
Temperatureonnot available
SFLPoffon: game rotation vector, gravity vector, gyro bias; 240 Hz (or 120)
Turning fusion on changes the ranges. After switching to B, set low-g ±16 g and gyro ±500 dps again. analyze.py prints the ranges it found ("ranges: acc_l +-16, gyro +-500"): check that line after the first run of each setting.

4. Mounting on the sander

Orientations

Z up (plate flat, as on the tractor), then on its side, Y up (plate on its left or right edge), so the vibration hits other axes. Not X up: with X pointing up the pitch is 90° and roll is undefined, so the tilt numbers mean nothing.

5. One run, step by step

About 5 minutes. Run names: r01, r02 … Fill in the run log (section 8) as you go.

  1. Plate set, sander off, nothing touching the rig. Settings A or B checked in MEMS Studio.
  2. Start the logger in a terminal: 
    cd FOLDER_WITH_THE_SCRIPTS
caffeinate -i python3 field_log.py --out ~/imu-runs/r01
    cd FOLDER_WITH_THE_SCRIPTS
python field_log.py --out C:\imu-runs\r01
    It prints TM171 on …, then the TM171's roll and pitch once a second, and writes r01_tm171.csv. (It skips the port MEMS Studio holds. If it finds nothing, add --tm171 and the port, COM5 from Device Manager.) If a lead is knocked out it says "dropped" and carries on when it is back in.
  3. Start logging in MEMS Studio. Note the file name.
  4. Wait 5 s. Tap the plate sharply once with the screwdriver handle.
  5. 60 s still. Hands off.
  6. Press Enter in the logger terminal, then switch the power strip on.
  7. 120 s running.
  8. Switch off, then press Enter.
  9. 60 s still. Wait for the sander to stop completely first.
  10. Tap again. Wait 5 s.
  11. Stop MEMS Studio logging, then Ctrl-C in the logger terminal.
  12. Check the run (section 6) before changing anything.
Taps: hard enough to show (over 10 dps on the gyro), once each, at the start and the end. The two taps line the logs up and correct the TM171's clock, which runs about 0.27 % fast. The TM171 often misses them; the script then lines the logs up on the shaking.

9. On the tractor (B5)

At rest, engine runs: one long run per setting (A, then B)

  1. Start the logger and MEMS Studio, tap, 5 min engine off.
  2. Enter, start the engine, 5 min idle.
  3. Enter, 5 min at working revs (PTO speed, PTO off).
  4. Enter, engine off, 2 min still, tap, stop MEMS Studio and the logger.

Nothing moves the tractor, so the true roll is constant: any shift when the engine starts is error, no reference needed. A tap on the plate with the engine running may not show above the vibration; tap firmly, and tap again at the end with the engine off.

Bush hog, parked, PTO on: one run per setting (A, then B)

The implement's own shaking (blades, gearbox, the driveline's joints at twice PTO speed) on top of the engine's, still with a constant true roll: no reference needed. Worn or chipped blades shake more; note their state.

  1. Start the logger and MEMS Studio, tap, 3 min engine off.
  2. Enter, start the engine, 2 min at working revs, PTO off.
  3. Enter, PTO on at 540, 5 min.
  4. Enter, PTO off, wait for the blades to stop, engine off, 2 min still, tap, stop MEMS Studio and the logger.

Driving runs with the bush hog (setting A; B too if there is time)

The dual-antenna receiver's roll is the reference: its antennas side by side across the tractor (the AgOpenGPS layout), so the receiver's "pitch" is the tractor's roll. Its speed and heading also let our fusion try GNSS aiding later.

  1. Start the logger and MEMS Studio, tap, 2 min still, engine running, PTO off.
  2. Enter, PTO on, straight pass mowing, steady speed, at least 2 min.
  3. Enter, headland turn.
  4. Enter, the same pass back the other way (a slope's roll changes sign: it shows any offset).
  5. Enter, a side slope along the contour, and a rough patch if there is one.
  6. Enter, stop, PTO off, 2 min still, tap, stop MEMS Studio and the logger.

One Enter in the logger's terminal marks both its logs at each change; note the time of each manoeuvre in the run log too. The receiver's log and the TM171's carry the laptop's clock, so all three line up.
